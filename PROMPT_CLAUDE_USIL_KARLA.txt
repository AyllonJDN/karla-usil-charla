Estamos construyendo una PRESENTACIÓN WEB para una charla de Karla Rodríguez en USIL × Global Leaders Club.

OBJETIVO
Quiero una presentación web que se comporte como PowerPoint, no como una landing page ni como un informe con scroll. Debe servir para compartir pantalla durante una charla. Son EXACTAMENTE 15 diapositivas en formato 16:9.

La web debe:
1. Mostrar una sola diapositiva por vez, centrada, respetando proporción 16:9 y escalando al viewport.
2. Navegar con flechas izquierda/derecha, teclas PageUp/PageDown, espacio y botones discretos.
3. Tener modo fullscreen.
4. Mostrar contador de slide muy discreto.
5. Tener un menú mínimo con: “Presentar”, “Descargar PDF”, “Descargar PPTX”.
6. Permitir exportar el estado ACTUAL de las 15 slides a PDF con html2canvas + jsPDF, una slide por página 16:9.
7. El botón PPTX debe descargar el archivo estático ubicado en /public/downloads/Karla_USIL_Creator_Economy_15slides.pptx.
8. También deja disponible el PDF estático base en /public/downloads/Karla_USIL_Creator_Economy_15slides.pdf, pero el botón principal de PDF debe exportar la versión actual de la web.
9. En modo presentación, ocultar todos los controles salvo un hotspot o botón mínimo para salir.
10. No debe haber scroll vertical entre slides.

STACK
- Vite + React + TypeScript.
- CSS limpio o Tailwind si ya está configurado.
- framer-motion solo para transiciones suaves.
- lucide-react para iconos.
- html2canvas + jspdf para exportar a PDF.
- No usar Recharts: esta presentación no necesita dashboards.

IMPORTANTE PARA ESTE EQUIPO
Trabajamos en Windows PowerShell y se usa npm.cmd, nunca npm a secas si PowerShell intenta abrir npm.ps1.
No cambies ExecutionPolicy.

DIRECCIÓN VISUAL
La referencia de organización es la presentación comercial de Wendy Wunder: diseño editorial, titulares grandes, una sola idea dominante por slide, bloques limpios, layouts divididos, tarjetas editoriales simples, uso de métricas grandes, slides de caso y cierre fuerte.
NO copies su paleta ni su identidad. Traslada esa lógica al universo visual de Karla/Matiz.

Firma visual:
- Titulares serif ligeros.
- Una palabra o frase corta en italic como acento por titular.
- En fondo claro: italic coral.
- En fondo oscuro: italic celeste.
- Mucho aire.
- Evitar cards genéricas de SaaS, sombras fuertes, glow excesivo, iconografía innecesaria y look de dashboard.
- Los fondos claros pueden ir de #FFFAF5 a un celeste extremadamente suave.
- Fondos oscuros principalmente #470B24 / #2A0615.
- Usar líneas finas coral o celeste y curvas/óvalos de trazo muy tenue como ornamento editorial.
- No llenar slides con texto.
- No convertir cada punto en tarjeta: usar tarjetas solo cuando aportan estructura.
